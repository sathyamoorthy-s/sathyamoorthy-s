## Featured Project

### [Job Application Tracker — End-to-End DevOps Project](https://github.com/sathyamoorthy-s/Job-application-tracker)

Built a Flask-based Job Application Tracker and implemented a complete end-to-end DevOps workflow covering development, testing, CI/CD, security scanning, containerization, AWS, Kubernetes, GitOps, and monitoring.

**DevOps Workflow:**

`GitHub → GitHub Actions → Pytest → SonarCloud → Trivy → Docker → Amazon ECR → K3s/Kubernetes → Argo CD → Traefik → Prometheus → Grafana`

### Key Implementation

- Built a Flask application with automated testing using **Pytest**.
- Implemented **GitHub Actions** for automated CI/CD workflows.
- Integrated **SonarCloud** for static code analysis and code quality checks.
- Integrated **Trivy** for container security scanning.
- Built Docker images and published them to **Amazon ECR**.
- Configured **AWS IAM OIDC** authentication for GitHub Actions without long-lived AWS credentials.
- Deployed the application to **K3s Kubernetes running on AWS EC2**.
- Used Kubernetes Deployments, Services, ConfigMaps, Secrets, and Ingress.
- Implemented **Argo CD GitOps** for automated deployment and synchronization.
- Demonstrated GitOps-based application scaling through Git changes and Argo CD synchronization.
- Configured **Traefik** as the Kubernetes Ingress controller.
- Implemented monitoring using **Prometheus and Grafana**.
- Used **Jira** to plan, track, and manage application development work.
- Documented the implementation, deployment, troubleshooting, verification, and infrastructure workflow.

**Technologies:** Flask, Python, Pytest, Git, GitHub, Jira, GitHub Actions, SonarCloud, Docker, Trivy, Amazon ECR, AWS IAM OIDC, AWS EC2, Kubernetes, K3s, Helm, Argo CD, Traefik, Prometheus, Grafana
